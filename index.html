Add another snapshot

  1. Open the repo on GitHub → Actions → Deploy NeuroNet showcase.
  2. Click Run workflow and keep the workflow branch on main.
  3. Enter a branch, tag, or commit (for example v8 or demo-v10).
  4. Optionally set the version folder, label, and description, then run it.
Every snapshot starts with the demo dataset and its own browser database. Anything you change stays in that browser and that version.
Snapshots are generated from the git history of this repository.
